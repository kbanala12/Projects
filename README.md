This repository holds my data science and statistical analysis projects. 


## Showcase site

A portfolio site for these projects lives in [`site/`](site/) and deploys to
GitHub Pages from `main` via `.github/workflows/deploy.yml`. To run it
locally or add a project, see [`site/README.md`](site/README.md): every
project is one entry in `site/data/projects.json`, and `npm run discover`
scaffolds the entry for a new folder.
